# What is being compared

KV-Lingo Eq.3.4 is a surrogate objective, not an algebra error. For a fixed normalized nonnegative attention row and errors e_i, Jensen gives ||Σ a_i e_i||² ≤ Σ a_i ||e_i||². The token objective penalizes errors that could cancel in a particular readout; readout ridge explicitly models that cancellation. Whether it improves unseen decoding is an empirical question, especially when mapped K changes attention.

The baseline here follows Appendix O: w_i is attention mass averaged over all continuation queries **and target query heads**, one scalar per prefix token. K and V regressions use the same w. With X[n,1024] and Y[n,1024], G=Σ Xᵀ diag(w) X and C=Σ Xᵀ diag(w)Y; W=(G+.01 I)⁻¹C. Σ is over 400 conversations; no per-corpus mean is introduced.

For readout, output KV head h is read by two distinct GQA query heads. For each query head g in that group and continuation query j, z_hgj = A_hgj X and t_hgj = A_hgj Y_h. Accumulate G_h=Σ_examples mean_gj zᵀz and C_h=Σ_examples mean_gj zᵀt. Solve W_h=(G_h+.01 I)⁻¹C_h. Concatenate the eight W_h along output columns to obtain the same1024×1024 inference matrix as the baseline. Different query heads remain distinct observations, because mean(A)ᵀmean(A) ≠ mean(AᵀA). Direct numerical tests cover this distinction.

Each readout loss is averaged over m continuation positions and two grouped query heads, so each output head has one unit of query mass per conversation. This is the corresponding scale of baseline per-head reconstruction under normalized w. No length, head-count, or total-dataset scaling is secretly folded into λ. Each condition penalizes the entire V matrix's Frobenius norm with .01, and both use the same K matrix with .01.

No bias is fit in either condition: KV-Lingo's equation3.2 and mapper use a linear map. The NVIDIA recipe additionally centers features and fits bias, but this experiment imports its Tikhonov regularization only. Importing centering/bias or its FineWeb calibration corpus would change more than the requested components. There is no explicit inverse: FP64 Cholesky solves the positive-definite regularized equations, with an independently calculated normal-equation residual.

Both fresh fits use prefix-normalized attention as literally written in equation3.4. Teacher queries are native target continuation queries, computed with the real full causal model. Their logits are then normalized over prefix keys for the fitting objective. This is distinct from preserving the causal denominator over prefix plus past continuation. Under that alternative, prefix attention mass is usually less than1; an affine readout must use the A1 bias feature. The current no-bias derivation remains linear even for subnormalized attention, but its numerical objective would be different. This convention is explicitly frozen and shared by the two methods; old local causal fits are not used.

Inference never receives teacher attention or ground-truth answers. It runs the source prefix, applies the fitted K/V matrices, then applies target K normalization and RoPE once. The target computes its own attention. Therefore a lower oracle readout residual neither proves that attention under mapped K matches, nor guarantees lower KL or higher benchmark accuracy. Full held-out intrinsic metrics, continuation KL/CE and paired benchmark scores are all required to interpret the comparison.
