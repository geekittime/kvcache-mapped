## 2. 数据与论文一致性

- 数据源为论文指定的 Nemotron-SFT-Instruction-Following-Chat-v2，固定 revision，原始两个文件 hash 验证通过。
- 400 条拟合，64 条 held-out；各自一半 natural、一半 packed，reasoning on/off 交替；continuation 上限 2048。训练/验证的目标及填充对话 UUID 均无交叉。
- 从 raw message 独立重建 assistant turn、reasoning 区段、聊天模板、完整填充对话、拼接顺序与 token 截断，所有 464 条完全一致。每条目标 UUID 不作为自己的 filler；此检查不等价于证明原始语料不存在语义重复。
- **与作者样本不能声称完全相同**：作者未公开具体 UUID、抽样及 packing 代码。本地 natural 按 1k 长度箱抽样、packed 由完整 filler 对话加目标对话历史构成。论文描述随机移除并移到末尾的问答，本地实现没有恢复作者的精确 packing 顺序。
- 本地训练 prefix 共 **3,809,293 tokens**，论文写约 **2.8M**。因此“同数据源、按公开规则构造”成立，“作者原始训练样本逐条复现”不成立。该差异同时作用于两个条件，仍可做固定本地数据上的配对比较。
- ARC-C/MMLU-Pro 的选中记录与 raw parquet 逐条核对；Hotpot 全 7,405 条 prompt 从 raw distractor validation 重建，未附加 gold/supporting facts。已有证据在 `checks/benchmark_source_review.json`、`hotpot_source_review.json`。

## 3. 数学与实现

共同部分为 28 层同层映射、head mixing、分开 K/V、pre-k-norm/pre-RoPE、无 bias。只引入 NVIDIA 的 λ=0.01 ridge 项，没有引入该论文的 affine/centering、跨层选择或 FineWeb 校准集。两组 K 使用同一拟合解并逐字节比较。

weighted 的 token 权重是 continuation 所有 query 和所有 query heads 的 attention 均值。readout 针对每个目标 KV head，保留对应两个 query heads 的独立 attention 行，先算 AX、AY，再求 Gram/cross；不会先平均 attention 再计算 Gram。所有 source V heads 均可作为特征。统计和求解 FP64，保存 FP32；teacher BF16，softmax FP32。正则化加到 corpus-sum Gram 的对角线，用 Cholesky 求解，不显式求逆。

readout 每个 KV head 使用 1/(Gm) 归一化，保持每个样本的权重不随 continuation 长度增加；weighted 使用全 query/head 均值。λ 是相同数值，但两个设计矩阵的谱与尺度不同，**不能解释为两组具有完全相同的有效正则化强度**。这也是报告必须注明归一化的原因。

prefix-only softmax 是对论文 Eq.3.4 的字面实现；不声称已由作者源码验证。真实生成的 attention 还包括 continuation keys，且 mapped K 改变 query/attention，因此该 readout loss 是固定 native teacher attention 下的代理目标，不是端到端生成损失的精确闭式最小化。

**KV-Lingo weighted loss 本身不是数学错误。** 对非负且和为 1 的 attention，Jensen 不等式给出 `||Σ a_i e_i||² ≤ Σ a_i ||e_i||²`；它是较保守的上界。readout 保留交叉项，也可能允许误差抵消。更小的训练 readout loss 不保证更好的 held-out KL 或任务准确率。

此外，此比较不只是在同一个矩阵上“加上非对角项”：readout 的对角项为 a_i²，weighted 为 a_i，而且本地 baseline 全 head 平均，readout 区分目标 KV head。结果应称为两个完整 V 目标的对照，不能单独把增益归因于交叉项。若后续要分解原因，需要另设诊断对照，不能在看到测试分数后改变本轮定义。

## 4. 缓存注入和预测位置

已有真实模型检查覆盖两个模型的 identity cache、split logits、不同长度左 padding，以及约 16k prefix 的所有 28 层 teacher attention/readout capture。目标 key norm、RoPE 只应用一次；源 prefix 翻译到最后一个模板 token 之前，最后一个模板 token 由目标模型原生处理。

本轮新增 tiny Qwen3 因果性检查：在相同 prefix 后加入 continuation 不会改变 prefix K/V；并检查捕获的 query、prefix key 范围。此前新增的 decoder 检查把 131-token teacher forcing 与整段 forward 对比，覆盖 64/128 两个 chunk 边界，避免 off-by-one。

真实 32k RULER、batch=4 的两方向注入已通过，但只用 smoke mapper 和 16-token 生成上限；这是容量/执行检查，不是 2,048-token 正式评测已经通过。

## 5. 评分、范围及结论边界

| 数据集 | 固定本轮范围 | 注意事项 |
|---|---|---|
| ARC-C | 1,172，off/on，1,024/8,192 新 token | generate-and-parse；本地 prompt/parser，非作者未公开 harness |
| MMLU-Pro | 1,400，14 类各 100，off/on，同上预算 | 主指标 macro accuracy；不是全 test 集 |
| RULER | niah_single_2，4/8/16/32k，各 400，off/on，2,048 新 token | 仅该 NIAH 子任务；不能汇报成整个 RULER 套件综合分 |
| HotpotQA | distractor validation 全 7,405，off，256 新 token | 用户扩展；不是该论文原始 benchmark；报告提取后 EM/F1 和 raw EM/F1 |

NIAH recall 在相同处理后的文本上与下载的官方 `string_match_all` 交叉测试一致。reasoning 区段去除是明确的本地前处理，不能称为与未去 reasoning 的官方原始文本评分逐字等价。Hotpot 使用标准大小写/标点/冠词归一化和 yes/no/noanswer F1 特例；答案提取只读模型输出，不读 reference。MC 未解析、生成上限停止的样本保留在分母中，不能跳过。

正式评测两种 mapper 使用相同数据、顺序、prompt IDs、生成预算、batch size、greedy decoding。报告先复核每一条输出再做配对差值；2,000 次配对 bootstrap（MMLU 按类别分层）描述测试样本抽样不确定性，不代表训练随机种子的不确定性。
